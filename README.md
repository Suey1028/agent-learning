
# Agent Development Learning

My 30-day journey to learn AI Agent development.

## Day 1: Python Fundamentals

Completed exercises:

- Python functions and dictionaries
- Exception handling
- HTTP API requests using HTTPX
- JSON parsing and file storage
- Python classes and objects
- API client development

## Project Structure

- `day01/order_tools.py`: Order lookup
- `day01/api_practice.py`: User API requests
- `day01/storage.py`: JSON file storage
- `day01/user_client.py`: Class-based API client

## Run Day 1

```bash
pip install -r day01/requirements.txt
cd day01
python main.py
```
